# Scarlett Hollow Enhanced Save Editor

A browser-based save editor for **Scarlett Hollow**

## Live Site (GitHub Pages)

- `https://FridgeFreezerUnit.github.io/Scarlet-Hollow-Save-Editor/`

## Features

- Trait editing for supported Scarlett Hollow trait variables
- Original trait detection and display
- Anti-cheat flag reset options
- Related flag cleanup when disabling traits
- Works offline (no external CDN dependency)
- Drag-and-drop `.save` support

## How To Use

1. Open the editor in your browser.
2. Load a Scarlett Hollow `.save` file.
3. Toggle traits/settings as needed.
4. Download the modified save.
5. Replace your save file in the Ren'Py save directory (back up first).

## Save Location (Windows)

Typical location:

- `%APPDATA%/RenPy/ScarletHollow-xxxxxxxx/`
